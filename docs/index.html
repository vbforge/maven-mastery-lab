// The loop

Read · Implement · Prove · Touch

Every module follows the same four-step loop. You always know where to look, and every concept is anchored by code you wrote yourself.

STEP 01

Read the module README

The source of truth for what's covered, the tasks table, and the key things to remember.

STEP 02

Run the Demo

A self-contained, annotated class with a main(). Read it top to bottom.

STEP 03

Implement the Tasks

Stubs that throw UnsupportedOperationException. Standard library only. Make the tests green.

STEP 04

Do the CLI lab

The things a unit test cannot show: dependency:tree, help:effective-pom, reactor logs.

// Quick start

Clone, build, run

Only a JDK is required. The Maven Wrapper pins the Maven version, so a fresh clone on any machine builds the same way.

~/dev/maven-mastery-lab — bash
# clone and build everything enabled in the root pom
$ git clone https://github.com/vbforge/maven-mastery-lab.git
$ cd maven-mastery-lab
$ ./mvnw clean verify
[INFO] Reactor Build Order:
[INFO] maven-mastery-lab [pom]
[INFO] 01-maven-recap [jar]
[INFO] BUILD SUCCESS
 
# run a single module's tests
$ ./mvnw test -pl 01-maven-recap
 
# run a module's teaching demo
$ ./mvnw -q exec:java -pl 01-maven-recap \
-Dexec.mainClass="com.vbforge.maven_recap.MavenDemo"
=== pom.xml ===
=== Coordinates ===
=== Dependency scopes ===
=== Lifecycle ===
 
# only the task tests, after removing @Disabled
$ ./mvnw test -pl 01-maven-recap -Dtest=MavenTasksTest
[INFO] Tests run: 22, Failures: 0, Errors: 0, Skipped: 0
[INFO] BUILD SUCCESS
